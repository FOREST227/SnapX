SnapX — macOS 截图工具
========================

安装方法：
将 SnapX.app 拖入 Applications（应用程序）文件夹。

首次打开：
GitHub 发布包使用临时签名，未经过 Apple 公证。
如提示无法验证开发者，请确认安装包来自官方 Releases，
再在“系统设置 → 隐私与安全性”中允许打开。

更新方式：
应用已移除自动更新，请从菜单中的“GitHub 发布页”手动下载新版。

功能简介：
- 框选截图 / 全屏截图
- 7 种标注工具（矩形、高亮、文字、箭头、直线、画笔、马赛克）
- OCR 文字提取
- 钉图置顶
- 截图历史
- ⌘Z 撤销标注，⌘Y / ⇧⌘Z 重做标注

默认快捷键：
- ⌘⇧S  框选截图
- ⌘⇧F  全屏截图
- ⌘⇧H  截图历史

项目主页：https://github.com/Forest227/SnapX
