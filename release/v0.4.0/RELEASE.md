# SnapX v0.4.0

新增默认关闭的「智能边缘吸附」，用于试验更容易对齐的截图选区。随正常版本提供，通过设置中的实验开关启用。

## 开启与使用

1. 打开设置，找到「实验性功能」，开启「智能边缘吸附」。
2. 触发框选截图，拖出一个大致范围；四条边靠近明显表格线、面板边界或色块分隔时，在约 6pt 内吸附。
3. 蓝线表示该边已吸附；按住 Option（⌥）临时关闭吸附，自由框选。松开鼠标后按预览范围进入编辑。

## 首版范围

- 支持表格线和明显横向、纵向界面的边缘辅助，不要求额外辅助功能授权。
- 冻结模式分析同一张冻结画面；实时模式在后台定期分析选框下方的画面，不把遮罩和选框自身当成边缘。
- 像素分析在本机完成，不上传图片、不使用云端模型；退出框选后取消后台任务。
- 关闭实验开关时保留原有框选行为，单击窗口、全屏截图和冻结时机不变。

## 已知限制

这是辅助拖动框选的实验功能，不会自动选中完整有效表格，也没有内部面板悬停识别或 Tab 层级切换。

无边框、弱对比、密集网格、曲线边界或持续变化的画面可能漏识别或吸附到相邻边缘。较大的屏幕会缩小后分析，极细线条的精度可能下降。请检查选区，必要时按住 Option 或关闭开关。

## 下载

需要 macOS 13 或更新版本。提供 arm64、x86_64、universal 的 DMG 和 ZIP，以及 SHA256SUMS.txt。公开安装包使用临时签名，尚未经过 Apple 公证；本机自行编译可以继续使用固定签名。
