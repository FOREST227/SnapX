# SnapX v0.3.0

本次更新重点改善文字标注、历史看图，以及主页面和设置页的使用体验。

## 文字与标注

- 重做文字输入：明确的输入边框、多行与自动换行，Enter 换行、⌘Enter 完成、Esc 取消修改。
- 支持选中文字后拖动、双击再次编辑；新增、移动和修改均可撤销、重做。
- 修复输入焦点、旧回调和数字快捷键抢占；调整样式时保留光标选区，并保护输入法组合文本。
- 字号、粗体、斜体和下划线集中到文字工具下方气泡栏。
- 高亮支持 0%–100% 透明度，马赛克支持笔刷大小调节。
- 更换荧光笔笔头图标，马赛克使用深浅九宫格，改善工具栏对齐及浅色分隔线。

## 截图历史与大图浏览

- 改为左侧缩略图、右侧大图预览，支持 ⌘ 多选、Shift 连选及批量操作。
- 空格打开独立大图窗口，Esc 返回；方向键切图，删除当前图片后选择邻近图片。
- 支持鼠标位置缩放、触控板捏合、拖动平移、双击切换适配与 100% 原始像素。
- 增加缩放比例、像素尺寸、适配按钮和透明棋盘格。
- 修复历史窗口随内容变化缩成窄栏的问题。

## 提取文字与界面

- 修复 OCR 结果窗口布局，增加“复制全部”、持续识别进度及具体失败提示。
- 退出编辑器后不再弹出迟到的识别结果或覆盖剪贴板。
- 主页面按钮统一高度、圆角和内边距；清空钉图可用时显示红色。
- 主页面与设置页共用固定坐标渐变，统一视觉明暗；改善深色层次与浅色绿色强调色。
- 添加外观选项滑动动画和整页明暗过渡，兼容系统“减少动态效果”。
- 修复主菜单的主题同步，并让菜单栏图标保留系统外观。
- 修复鼠标穿透说明截断，移除设置页重复的应用名称。

## 下载

- Apple 芯片：`arm64`
- Intel 芯片：`x86_64`
- 两种芯片通用：`universal`

每种架构均提供 DMG 和 ZIP，另附 SHA256SUMS.txt 校验文件。需要 macOS 13 或更新版本。

公开安装包使用临时签名，尚未经过 Apple 公证。自行编译长期使用时可继续采用固定本机签名。

历史记录仅保存在本次运行期间，退出应用后清空。应用不含自动更新功能，请通过 GitHub 发布页下载新版。
