# SnapX v0.2.0

本次更新集中修复截图确认、快捷键和编辑交互，并统一主面板与设置页的视觉样式。

## 截图与编辑

- 明确两种截图方式：**触发时冻结**，以及**选区确认时冻结**。
- 确认后，选区、编辑背景和再次调整选框共用同一张画面，避免内容变化或消失。
- 冻结失败时取消截图，不再自动切换为实时取图。
- 窗口识别在冻结模式下使用触发时的窗口位置。
- 保留框选遮罩，通过排除遮罩的方式取图，减少确认到编辑之间的闪烁。
- 马赛克预览改为首次使用工具时生成，减少编辑首屏的额外处理。
- 修复首次点击只激活窗口、需要再次点击才能确认的问题。
- 跨屏窗口按当前屏幕可见范围框选，修复屏幕边缘裁剪后被拉伸的问题。
- 新增 **⌘Y / ⇧⌘Z 重做标注**，与 ⌘Z 撤销配合；新增或修改标注后清空旧重做记录。裁剪暂不支持撤销、重做。

## 快捷键

- 修复多个监听器互相吞掉事件，导致自定义快捷键（例如 ⌥S）不触发的问题。
- 快捷键注册成功后才保存；冲突时保留原设置，并显示具体错误。
- 录入失去焦点或窗口关闭时退出录入，恢复全局快捷键。

## 设置与外观

- 重新组织截图方式、快捷键、通用设置和权限区域。
- 主面板与设置页统一为 320pt 宽度，共用背景、强调色和状态色。
- 快捷键输入框与外观选择器统一底色、边框和圆角。
- 提高说明文字对比度和字号，改善浅色、深色模式下的可读性。
- 增加快捷键录入成功反馈，以及权限状态与系统设置入口。
- 修复从指定主题切回“跟随系统”后仍保留旧外观的问题。

## 更新与本机构建

- 移除“检查更新”、后台自动更新及 Sparkle 依赖。以后请从 **GitHub 发布页**手动下载安装新版。
- 修复通用版构建时不同架构输出互相覆盖的问题。
- 增加固定本地自签名证书的初始化与安装脚本。复用原证书，并在安装前备份旧版应用。
- 本地固定签名可改善反复构建后的权限保留；GitHub 安装包仍使用临时签名，不包含开发者的本机证书或私钥。

## 下载与安装

- **Apple Silicon（M 系列）**：选择 `arm64.dmg` 或 `arm64.zip`。
- **Intel Mac**：选择 `x86_64.dmg` 或 `x86_64.zip`。
- **通用版**：选择 `universal.dmg` 或 `universal.zip`。

需要 macOS 13 或更新版本。退出旧版后将 SnapX.app 放入“应用程序”文件夹。
发布包未经过 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中允许打开。屏幕录制和辅助功能权限由 macOS 管理；从本地固定签名版换用 GitHub 安装包时可能需要重新授权。
