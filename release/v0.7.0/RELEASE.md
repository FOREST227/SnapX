# SnapX v0.7.0

这一版重做菜单栏面板与设置窗口的视觉，统一全应用的强调色，让界面更安静、更贴近 macOS 原生风格。

## 菜单栏面板

- **原生毛玻璃材质**：面板不再自绘渐变背景，直接使用系统弹出面板材质，浅色模式不再发灰。
- **权限状态收起**：权限齐备时只在标题右侧显示「已就绪」小绿点；缺少权限时才展开橙色提示条和授权按钮。
- **一个主操作**：只保留「框选截图」为实心按钮，「全屏截图」「截图历史」改为无边框菜单行，悬停时显示高亮，快捷键右对齐显示。
- **钉图控制更紧凑**：透明度、鼠标穿透与「清空」归为一组，不再使用卡片容器。
- **底部工具行**：设置、GitHub 发布页、重启、退出收进底部一行小图标，钉图数量与版本号显示在左侧。
- 打开面板时内容轻微上移渐显，遵循系统「减少动态效果」设置。

## 设置窗口

- 标题、分组标题与说明文字统一字重和层级；分组容器更轻、圆角更小。
- 「截图方式」由两张大卡片改为单选列表，流程说明以小字显示在右侧。
- 权限项合并为单行，用状态圆点区分已授权与未授权。
- 快捷键按键框、外观切换、实验性功能控件尺寸收紧，视觉更统一。
- 共用背景的浅色渐变更柔和，去掉斜向高光。

## 统一强调色

- 截图选区框与编辑器选区框由绿色改为系统强调色，与按钮、选中状态保持一致。
- 智能边缘吸附锁定的边改为绿色显示，在蓝色选区框上依然一眼可辨。
- 编辑工具栏仅当前工具与「完成」保留底色，其余按钮默认无底、悬停时高亮。
- 历史窗口缩略图选中态改为更细的描边；删除按钮与复制、钉住、保存分开放置，减少误触。

## 安装

支持 macOS 13 及更新版本。提供 Apple 芯片（arm64）、Intel（x86_64）和通用版（universal），各含 DMG、ZIP 及 SHA256 校验信息。

公开安装包使用临时签名，尚未经过 Apple 公证；本机固定签名的构建与安装流程继续保留。
