# SnapX v0.3.2

全新应用图标，更清爽的设置界面，以及更方便的钉图鼠标穿透操作。

## 新图标与外观

- 采用瓷白底、深浅蓝交错 X 和加粗四角截图框的新图标，更新全部尺寸资源。
- 主页面与设置页统一银灰渐变、蓝色强调色、绿色状态图标及瓷白控件底色。
- 设置页隐藏独立标题栏视觉，保留系统窗口按钮，并预留固定顶部区域，滚动内容不再遮挡按钮。
- 右侧改为细浮动滚动条，不增加内容模糊或渐隐。
- 优化浅色、深色切换：移除整窗截图叠加造成的卡顿，保留轻量背景过渡。

## 快捷键设置

- 录入框降低高度，调整符号间距与标题居中对齐。
- 用蓝色边框动画和短暂绿色对勾替代“录入中”“已生效”文字。
- 无效组合保留在输入框中，以橙色边框和告警图标提示；点击图标查看错误原因，原快捷键仍然有效。
- 错误状态下按 Esc 可恢复上一次成功保存的快捷键，不再依赖按钮焦点；错误详情弹出时也可恢复。

## 钉图鼠标穿透

- 双击左上角图钉，单独开启或关闭当前钉图的鼠标穿透。
- 开启后仅保留蓝色图钉手柄，隐藏其余工具按钮。
- 穿透期间仍可拖动图钉移动窗口，再次双击即可恢复正常操作。
- 保留菜单栏统一控制与 Option 拖动交互。

## 下载

提供 Apple 芯片（arm64）、Intel（x86_64）及通用（universal）版本，每种架构均有 DMG、ZIP，另附 SHA256SUMS.txt。需要 macOS 13 或更新版本。

公开安装包采用临时签名，尚未经过 Apple 公证。自行编译长期使用时，可继续采用固定本机签名。
