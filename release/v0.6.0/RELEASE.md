# SnapX v0.6.0

这一版统一界面布局与动画节奏，修复调整裁剪框丢失标注的问题，并让撤销能覆盖裁剪操作。

## 裁剪不再丢标注

- **调整裁剪框保留全部标注**：拖动选框边缘重新裁剪后，线框、荧光笔、文字、箭头、直线、画笔和马赛克会跟随画面平移到新坐标，完全落在新选区外的标记才会移除。
- **裁剪可以撤销**：撤销记录从仅保存标注升级为同时保存画面与选框，⌘Z 可逐步退回裁剪前的状态，重做同样支持。
- 拖动裁剪框时，标注保持全亮显示在原位，可直接看清哪些标记将被保留、哪些会被裁掉；此前整层会淡到几乎看不见。

## 编辑工具栏更稳

- **工具栏宽度固定**：颜色选择收进独立的色点按钮，点击弹出九色色盘；切换到马赛克等不支持颜色的工具时按钮不再整体跳动。
- 色盘与工具属性气泡共用同一套浮层样式，Esc 先关闭色盘再关闭编辑器。
- 「关闭」按钮改为中性底红色图标，不再和蓝色的「完成」争夺视觉焦点。
- 修复工具栏宽度估算偏小、在特定截图尺寸下可能超出屏幕边缘的问题；属性气泡高度改为实测，荧光笔设置项不再溢出。

## 提示与反馈到位

- Toast 提示从屏幕左上角移到截图上方；失败信息（保存失败、提取失败等）改用黄色警示图标，不再误用对勾。
- 工具快捷键提示居中于截图，只在前三次进入编辑器时显示，绘制或切换工具后立即消失。
- 框选时的尺寸浮签与提示浮层样式统一；框选到进入编辑器的选框颜色、圆角、遮罩深浅完全一致，过渡不再有视觉跳变。

## 动画统一节奏

- 全部弹性回弹动画替换为统一的 220ms 进入 / 160ms 退出缓动曲线。
- 所有新增动画都遵循系统「减少动态效果」设置。
- 钉图出现时有 0.18s 淡入，关闭时 0.12s 淡出。

## 菜单面板更精简

- 权限齐备时权限卡片收缩为单行「权限已就绪」加当前快捷键。
- 「清空钉图」从大号红色按钮收进钉图卡片底部的小号操作，并跟随钉图数量禁用。
- 设置、GitHub 发布页、重启、退出改为左对齐列表行并带悬停反馈；「退出 SnapX」标红。
- 状态栏图标换为与应用图标一致的「取景框 + X」模板图标，更容易在一排相机类图标中辨认。
- 历史窗口空状态新增「框选截图」入口按钮。

## 其他

- 截图方式默认值调整为「触发时冻结」，新装用户开箱即先冻结画面再框选。
- 设置中快捷键保存成功的对勾停留时间由 0.4s 延长到 1.2s，更容易察觉。

## 安装

支持 macOS 13 及更新版本。提供 Apple 芯片（arm64）、Intel（x86_64）和通用版（universal），各含 DMG、ZIP 及 SHA256 校验信息。

公开安装包使用临时签名，尚未经过 Apple 公证；本机固定签名的构建与安装流程继续保留。
