# SnapX v0.5.0

这一版重点改进截图后的标注与取字体验，并完善实验性智能边缘吸附。

## 标注更自然

- **真正的荧光笔涂抹**：按住鼠标连续绘制，替代原来的透明矩形。默认笔刷 24pt，可在 8–64pt 调整，保留颜色与透明度设置。同一笔来回涂抹保持均匀，多笔可叠加，支持逐笔撤销和重做。
- **平滑弧线箭头**：根据拖动方向拟合曲线，过滤细小抖动，箭头沿末端方向绘制。
- **文字输入更快**：单击后立即开始输入，减少重复文字排版；移除“输入文字”占位提示，中文输入法组合期间不再叠字。
- **浅色编辑工具栏**：浅白工具栏搭配无描边的浅灰按钮，提高工具之间的辨识度。
- 导出保留原图像素尺寸，并保留广色域截图的色彩配置。

## 文字识别更清晰

- 点击识别后，蓝色扫描线沿选区从上到下移动，整段约 450ms。
- 顶部 3/11 快速、中间 5/11 持续慢速、底部 3/11 快速，前后对称、分界平滑。
- 扫描与识别等待分开：扫描不会停在中间；若识别尚未结束，按钮继续显示处理中，真实结果就绪后再显示。
- 结果窗口采用与设置页一致的背景、标题和按钮样式，支持原生文字选择、复制及窗口缩放。
- 使用细浮动滚动条，不显示白色轨道，不给内容增加模糊或渐隐。
- 关闭编辑器或调整选区会取消当前结果投递，避免旧结果覆盖新操作。

## 实验性吸附更实用

仍然**默认关闭**，在「设置 → 实验性功能」中启用。

- 默认吸附范围调整为 **16pt**，支持 **4–32pt** 调节和恢复默认。
- 开始框选前提供蓝色起点提示，按下后锁定起点，改善首个锚点难以贴边的问题。
- 改善部分低对比面板分界的识别，支持常见圆角气泡，匹配完整区域时外留约 2pt。
- 按住 Option（⌥）仍可临时自由框选。

此功能用于辅助拖动框选，不会自动判断完整有效表格，也不支持悬停选中软件内部面板。弱对比、密集线条或复杂圆角可能识别不准，请检查选区。

## 安装

支持 macOS 13 及更新版本。提供 Apple 芯片（arm64）、Intel（x86_64）和通用版（universal），各含 DMG、ZIP 及 SHA256 校验信息。

公开安装包使用临时签名，尚未经过 Apple 公证；本机固定签名的构建与安装流程继续保留。
