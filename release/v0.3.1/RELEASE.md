# SnapX v0.3.1

本次更新优化钉图的查看与移动体验，并调整编辑工具栏和设置页。

## 钉图交互

- 改为约 1pt 薄边框，去掉独立的系统关闭按钮，悬停时在框内显示操作栏。
- 缩放只改变内部图片，窗口大小和位置保持不变。
- 最小缩放保持铺满窗口，允许裁切；缩回最小时保留查看位置，不再自动居中，只做避免露白的边界修正。
- 鼠标滚轮直接缩放，无需按住 ⌘；修复高精度鼠标滚轮被误判成触摸板滑动的问题。
- 触摸板双指捏合缩放，双指滑动平移；拖动图片也只平移内容。
- 新增左上角图钉形状的移动手柄，并保留 Option（⌥）拖动图片移动整个窗口。
- 拖动边框和边角调整窗口大小；右上角提供适配、复制原图和关闭操作。
- 保留不透明度、鼠标穿透和置顶行为。

## 界面调整

- 编辑工具栏关闭按钮改为鲜红底、白色 ×。
- 色板中的粉红色改为砖红色，与鲜红色更容易区分。
- 设置页快捷键符号增加间距，录入框略微加高。
- 外观切换改为带图标的滑动胶囊，移除竖分隔线和下划线，保留动画及减少动态效果支持。

## 下载

提供 Apple 芯片（arm64）、Intel（x86_64）及通用（universal）版本，每种架构均有 DMG、ZIP，另附 SHA256SUMS.txt。需要 macOS 13 或更新版本。

公开安装包采用临时签名，尚未经过 Apple 公证。自行编译长期使用时，可继续采用固定本机签名。
